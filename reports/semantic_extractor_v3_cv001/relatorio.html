O que cada medida significa

MedidaO que éO que deseja mostrar
Similaridade de cossenoProximidade angular entre dois embeddings; varia de -1 a 1.Quanto os textos estão próximos no espaço do modelo. Não confirma domínio de uma tecnologia e não é probabilidade.
Margem Top1–Top2Score da primeira entrada menos o da segunda. Varia de 0 a 2; N/A se houver só uma entrada.Quanto a primeira evidência se destaca da segunda. Margem pequena pode indicar alternativas igualmente relevantes; margem grande não garante correção.
Hit@1Fração dos requisitos positivos anotados com uma evidência aceitável em primeiro lugar.Se o primeiro resultado é útil. Valor entre 0 e 1; maior é melhor.
Hit@3Fração dos requisitos positivos anotados com alguma evidência aceitável entre as três primeiras entradas.Se a equipe encontra uma evidência correta ao revisar até três resultados. Valor entre 0 e 1; maior é melhor.
MRRMédia de 1/posição da primeira evidência aceitável; contribuição zero se ela não for recuperada.Quão cedo aparece uma evidência correta. Valor entre 0 e 1; maior é melhor. Primeiro lugar contribui 1, segundo 0,5 e terceiro 0,333.

Limites e próximo experimento

Os exemplos didáticos não validam desempenho geral. O gold atual é por entrada original; para blocos extensos, anote trechos específicos. Rankings agrupam chunks da mesma entrada para não inflar Hit@3 com sobreposição.

Amplie para vários currículos e vagas, com anotações revisadas pela equipe. Inclua paráfrases, casos relacionados sem comprovação e requisitos ausentes. Uma palavra relacionada, como Python, não confirma Pandas. Mantenha um teste independente para avaliar decisões futuras de modelagem.
